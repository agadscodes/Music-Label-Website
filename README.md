# Encore Recordings — Concept UI

A modern, minimalist record label landing page inspired by the editorial design of Encore Recordings. This project is a front-end experiment exploring music industry web aesthetics, responsive roster layouts, and interactive talent profile views.

> **Note:** This project is purely an experimental concept and study in front-end design/layout. It is not affiliated with, endorsed by, or officially connected to Encore Recordings.

---

## Features

* **Minimalist Brand Aesthetic:** High-contrast editorial styling built around custom design tokens.
* **Hero Section:** Clean branded header with a quick-scroll call to action.
* **Responsive Roster Grid:** 4-column desktop grid scaling down to mobile viewports with smooth hover transitions.
* **Artist Profile Modal:** Interactive overlay displaying expanded artist visual identity and label affiliation.
* **Optimized Assets:** Localized static asset management to prevent external CDN breakage and CORS issues.

---

## Tech Stack

* **Framework:** [React](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Icons:** [Simple Icons](https://simpleicons.org/) & [FontAwesome](https://fontawesome.com/)
* **Styling:** Plain CSS3 (Flexbox, Grid, CSS Variables)
